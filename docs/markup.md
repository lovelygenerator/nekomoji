# nekomoji マークアップ仕様(v0.1)

このファイルを唯一の正とする。AI にシナリオを書かせるときも、このファイルを渡す。

## 基本

- 文字はそのまま書く。ソースの改行は改行(`[br]`)になる(`\r\n` も `\n` と同じ)。ファイルの先頭の BOM(U+FEFF)は文字にしない(桁にも数えない)
- タグは `[名前 引数...]`、範囲タグは `[名前 ...]…[/名前]` で閉じる。入れ子は内側から閉じる
- 文字としての `[` `]` は二重にする(`[[` `]]`)。ルビの親文字・縦中横の中でも同じ。二重にしていない `]` はエラー。`{` `}` は普通の文字(二重にしない。`{{` は2文字の `{`)
- タグの書き方: 名前は小文字で、大文字小文字は区別する(`[B]` は知らないタグ)。引数は空白(1つ以上)で区切る。`[` の直後(閉じタグでは `/` の直後)に空白は書けない(`[ b]` はエラー)。タグは1行の中に書く(改行をまたぐとエラー)。閉じタグに引数は付けない
- 数の引数は ASCII の10進数(符号・小数・指数 `1e3` を書ける)。`nan`・`inf`・全角数字は引数の誤り。範囲はタグごとに下の表で決め、範囲の外は引数の誤り(`bad_arg`)。負の数を書けるのは `[shadow]` のずれだけ
- 色(`[color]` `[outline]` `[shadow]`)は、色名(`white` `black` `red` `green` `blue` `yellow` `cyan` `magenta` `pink` `orange` `gray` `grey` `lime` `aqua` `maroon` `olive` `teal` `navy` `purple` `fuchsia` `silver`。大文字小文字は区別しない)か、`#rgb`・`#rrggbb`(16進)。透明度は書けない(不透明度は文字に従う)。知らない色名・形の違う色は引数の誤り
- 名前・ID(`[mark]` `[icon]` `[var]` `[blip]` `[voice]` `[se]` `[event]`)は、空白と `[` を含まない 1〜64 文字。大文字小文字は区別する。`]` は書けない(タグがそこで閉じる)
- 同じ種類のタグを入れ子にしたときは内側が優先する(`color` `size` `speed` `outline` `shadow` `blip` `shake` `wave` `glow` `fade` `em` など)。`size` と `speed` も掛け算にしない(掛け算すると、上限の 10 倍・100 倍を超えて描画側が確保するメモリが足りなくなるため)。違う種類のタグは重ねて効く。`align` の入れ子だけは引数の誤り
- 知らないタグ・閉じ忘れ・引数の誤り(多すぎる引数を含む)は、行と桁つきのエラーになる。`parse` は最初のエラーを、`parse_all` はすべてのエラーを位置の順に返す(CLI の `check`・`log` はすべて出す)。エラーの後は連鎖しないように読み進める: `]` の無い `[` はその行の残りを読み飛ばし、エラーになった開きタグに対応する閉じタグは読み捨て、閉じる順を誤った閉じタグは同じ名前の開いているタグを閉じ、ルビの親文字・縦中横の中のエラーはその閉じタグまで読み飛ばす

## ルビの短い書き方

`｜親文字《よみ》`(`|` も可)は `[ruby よみ]親文字[/ruby]` と同じ。小説投稿サイトの書き方に合わせた略記で、縦線(全角 `｜` U+FF5C・半角 `|`)で始まり、形が合うときだけルビになる。

- 親文字は 1〜32 文字。空白・改行と `| ｜ 《 》 [ ]` は含められない
- 読みは空でなく、改行と `《 》 [ ]` を含まない(前後の空白は取る)
- 形が合わない縦線は文字のまま(`a|b`・`|親《》`・`|親 子《よみ》`)。エラーにはしない
- `||親《よみ》` は、最初の `|` が文字、その後ろがルビ(縦線そのものを書きたいときは直後に別の縦線を置くか、ルビの前に文字を挟む)
- 漢字だけの `親《よみ》`(縦線なし)はルビにしない。`《` `》` は文字のまま
- 前後のタグのスタイルを引き継ぐ。親文字に書けないものは `[ruby]` と同じ(エスケープは使えず、`[[` は親文字に含められないので `[ruby]` を使う)
- バックログ(`Page::text`)の `｜親文字《よみ》` は、この書き方で読み戻せる。短い書き方で書けないルビ(親文字が 33 文字以上・空白や括弧を含む、読みが `《》` を含む)だけは `[ruby よみ]親文字[/ruby]` の形で出す(`[` `]` は二重にする)ので、バックログの出力はいつでも読み戻せる

| `wave` | `[wave 強さ? 秒?]…[/wave]` | 波(強さの既定 1。0 より大きく 10 まで)。秒は `shake` と同じ |
| `fade` | `[fade 秒?]…[/fade]` | フェードイン(既定 0.3 秒)。秒は 0 以上(0 はすぐ出る。上限は無い) |

| `outline` | `[outline 色? 太さ?]…[/outline]` | 縁取り。字形の周りを太さの分だけ広げた形を、文字の後ろに塗る(背景の絵の上でも読めるように)。色は `[color]` と同じ書き方で既定は `black`、太さは字の大きさに対する比で既定 0.08(0 より大きく 0.5 まで。描画アダプタ `nekomoji-wgpu` は大きな字でも縁取りを太らせる半径を 64px で止めるので、大きな字に太い縁取りを付けても指定の太さにならないことがある)。最初の引数が数として読めなければ色。入れ子では内側が優先。ルビ・圏点にも親文字の縁取りが付く。不透明度は文字に従い、動きの強さの影響は受けない。端末では通常表示 |
| `shadow` | `[shadow 色? x? y?]…[/shadow]` | 影。字形と同じ形(縁取りがあれば縁取りの形)を、ずらして文字の後ろに塗る。色は既定 `black`、ずれは字の大きさに対する比で既定は右へ 0.06・下へ 0.06。書かなかった軸は既定のまま(x だけ書くと y は 0.06)。ずれは画面の向き(縦書きでも右・下が正)で、負の数なら左・上。絶対値は 10 まで。ほかは `outline` と同じ |
| `sup` | `[sup]…[/sup]` | 上付き。0.6 倍の大きさで、ベースラインを 0.4 上げる(周りの文字の大きさに対する比。`[size]` と掛け合わせる)。行の高さは変えない。入れ子・中のルビ・中の縦中横はエラー。端末では `^{…}` |
| `sub` | `[sub]…[/sub]` | 下付き。0.6 倍の大きさで、ベースラインを 0.15 下げる。ほかは `sup` と同じ。端末では `_{…}` |
| `s` | `[s]…[/s]` | 取り消し線。色は `[color]` に従い、ルビには引かない。端末では文字に U+0336 を重ねる |
| `u` | `[u]…[/u]` | 下線。縦書きでは行の右側(傍線)。ほかは `s` と同じ。端末では U+0332 |
| `em` | `[em 記号?]…[/em]` | 圏点(傍点)。1文字ごとに記号を付ける(横書きでは上、縦書きでは右)。既定はゴマ点 `﹅`、引数で記号を選べる(`[em ●]`。Unicode の1文字で、制御文字は不可)。空白・句読点・括弧・ルビの親文字・アイコンには付けない。縦中横には塊に1つ。バックログには出さない |
| `tcy` | `[tcy]…[/tcy]` | 縦中横。縦書きで中の文字を立てたまま横に並べ、全角1文字分に収める(収まらなければ横に縮める)。中にタグ・改行・変数は書けない(エスケープは書ける)。1文字以上で、長さの上限は無い(収まらなければ横に縮める。2〜3 文字が目安)。上付き・下付きの中では使えない。横書きでは普通に並ぶ(途中で分けない)。端末の縦書きでは1段に横に並べる |
| `mark` | `[mark id]…[/mark]` | 名前付きの範囲。見た目は変えず、範囲の ID を描画側・ゲーム側へ渡す(用語の説明・クリックできる語・特定の語の強調など)。ID は空白を含まない1語で、ちょうど1つ書く。入れ子にでき、同じ ID を何か所に書いてもよい。ルビ・縦中横・変数を囲める。範囲は文字の並びと、行ごとの矩形・当たり判定で取り出せる(`Layout::marks`・`Layout::mark_spans`・`Page::hit_test`)。端末の `log` では範囲の一覧を出す |

| `blip` | `[blip 音?]…[/blip]` | 文字送りの音(RPG の「ポポポ」)。範囲の文字が出るとき、何文字かごとに出来事 `blip 音` を出す(再生は利用者側)。音を省くと設定の音(既定 `blip`)、`off` で鳴らさない(`off` という名前の音は使えない)。話し手ごとに音を変えるのに使う。引数は0か1つ。詳しくは下の「文字送りの音」 |
| `neko` | `[neko 種類 強さ?]…[/neko]` | 猫の出し方(猫モード)。種類は今は `hop`(猫が跳ねるように現れる。左下から 0.35 秒で跳び上がって着地する)のみ。強さの既定 1(0 より大きく 10 まで)。知らない種類はエラー。端末では通常表示 |

縁取りと影は描画側にも既定を持てる(`nekomoji-wgpu` では `Placement::outline`・`Placement::shadow`)。既定はタグで囲んでいない文字(とそのルビ・圏点)に付き、タグがあればタグが優先する。テキスト全体を縁取るならシナリオにタグを書かず、描画側の既定で付ける。描く順は後ろから 影・発光の光・縁取り・文字。

## 文字の単位

1文字は書記素クラスタ(見た目の1文字)で数える。異体字セレクタ付きの漢字(`辻󠄀`)・結合文字(`か゛`・`é`)・ZWJ でつながる絵文字(`👨‍👩‍👧`)・国旗(`🇯🇵`)は1文字で、途中で改行せず、文字送りでも一度に出る。幅・禁則・句読点の間は先頭の文字で決める。ハングルの字母の組み合わせとインド系の文字の結合は扱わない。

## 変数

`[var name]` はレイアウト時に値で置き換える。値がなければ書いたとおり `[var name]` のまま表示し、警告を出す。値はマークアップとして読まない(`[b]` はそのまま文字)。値の改行(`\n`・`\r\n`)は改行(段落の区切り)になり、タブは空白にし、ほかの制御文字は捨てる。変数から来た文字は、どの変数から来たかを区別できる(`Glyph::var`)。

## クリック待ち

`[l]` はページの途中で入力を待つ(ノベルの「クリック待ち」)。改ページせず、入力すると同じページの続きを出す。

- 出来事は `TextEvent::WaitClick`。待っている間は `Reveal::is_waiting` が真で、種類は `Reveal::wait_kind`(`WaitKind::Click`。ページの終わりは `Page`、終了は `End`)。`Reveal::proceed` で続きへ進む(ページの終わりでは今までどおり次のページへ)
- 待った長さは `[wait]` と同じに数える: 続きの文字・合図・ページの終わりの時刻は、待った分だけ後ろへずれる(`Reveal::appear_times`・`page_end` はずらした値、`Reveal::timeline` は待たなかったときの値)
- `skip` は次の入力待ち(`[l]`・ページの終わり)の手前まで出す
- ページの終わり(後ろに文字が無い所)の `[l]` は待たない(ページの終わりの入力待ちと重なるので)。同じ位置に続けて書いても1度だけ待つ
- カーソル(`Reveal::cursor`)は表示済みの最後の文字の後ろに出て、`Cursor::kind` で種類が分かる
- 保存と復元: `RevealState::clicks` に、`[l]` から進んだ時刻を持つ(文字列では ` l<秒>,<秒>`)
- オートモード: `[l]` では、前の `[l]`(無ければページの始め)からの文字とボイスで待ち時間を決める(`Reveal::auto_wait_click`)。ページの終わりでは最後の `[l]` より後ろだけで数える
- 猫モード: `[l]` で待っている間、猫は表示済みの文字の上を歩くだけで、押して落とす・爆散はページの終わりだけ

## 読み上げ用のテキスト

`Page::speech_text()` は読み上げ(TTS)や読みでの検索に使うテキストを返す。ルビの親文字は読みに置き換え、圏点とアイコンは出さない。折り返しや自動改ページで分かれた行はつなぎ、段落(`Line::paragraph_start`)の区切りだけ改行にする。バックログの `Page::text()`(ルビは `｜親文字《よみ》`)とは別。CLI では `log --speech`、REPL では `:speech`。

## 元の文章との対応

配置した1文字(`Glyph`)は、元の文章(`parse` に渡した文字列)のバイト範囲(`Glyph::source`)を持つ。エスケープ(`[[`)は2バイト分、変数から来た文字は `[var name]` 全体を指す。エディタでの対応付けや、クリックした文字から元の行へ跳ぶのに使う。

## 猫モード

猫モードはタグではなく設定(`NekoMode`)で有効にする。シナリオに書くのは猫の出し方(`[neko hop]`)だけ。猫の絵は出さない。見えない猫が表示済みの文字の上を気ままに歩き回り、文字送り中はそばの文字を猫パンチで飛ばし、入力待ちでは最後の文字を押して落としたり、ときどきページの文字をまとめて爆散させたりする。飛んだ文字は数秒後に元の位置へフェードインで戻る。テキスト(バックログ・`log` 出力)は変わらない。入力待ちには肉球のカーソルを出す(描画側)。

CLI では `--neko`(`--seed` `--knock` `--burst` `--punch` `--no-walk` `--ascii`)、REPL では `:neko on`・`:knock`・`:burst`・`:punch` などで有効にする。

## 縦書き

縦書きもタグではなく設定(`LayoutOptions::writing` を `Writing::Vertical`)で切り替える。シナリオは横書きと同じものがそのまま使える。CLI では `--vertical`、REPL では `:writing tate`(`:writing yoko` で戻す)。

- 行は右から左へ並び、行の中は上から下へ進む。`--width`・`:width` は1行の高さ(全角の文字数)になる
- 禁則・ぶら下げ・ルビのはみ出しは横書きと同じ。ルビは親文字の右に付く
- 漢字・仮名・全角英数は立てて置き、半角英数・長音・ダッシュ・リーダー・括弧は寝かせる(フォントに縦書き用の字形があればそれを使う)。句読点と小書きの仮名は右上に寄る
- 上付きは右へ、下付きは左へずれる。取り消し線は行の中央、下線は行の右側に引く。端末の縦書きでは上付き・下付きは通常の文字として示す
- 縦中横は `[tcy]12[/tcy]` と書く。自動では縦中横にしない(半角英数は寝かせる)。2〜3 文字が目安

## 動きの強さ

光過敏や動きに弱い人のために、動きもタグではなく設定(`RevealOptions::motion`)で `Motion::Full`(標準)・`Reduced`(控えめ)・`Off`(なし)から選ぶ。シナリオは書き換えなくてよい。ゲームの設定画面の「演出」にそのままつなげられ、文字送りの途中でも `Reveal::set_motion` で切り替えられる。文字が出る時刻は変わらない。

- 控えめ: 揺れ・波・猫の跳ね方の振れ幅を 0.3 倍にし、揺れ・波は 1 秒以内に止める(跳ね方は回さない)。`breathe` の明滅を浅くし、`flicker` は 1 秒に 1 度までで浅く瞬き、文字は暗くしない。猫パンチと爆散はしない(押して落とすのは残す)
- なし: 揺れ・波・跳ね方は動かさない。発光は一定の明るさで光る。猫のちょっかいはしない。肉球のカーソルは明滅させない
- 標準でも `flicker` は 1 秒に 3 度を超えて瞬かない。瞬きの間の明るさのゆらぎも段差なくなめらかに変え(標準は 1 秒に 3 度・±15%、控えめは 1 秒に 1 度・±5% の速さ)、明滅の数を増やさない
- フェードイン・入力待ちのカーソルはどの強さでも出す

CLI では `--motion full|reduced|off`、REPL では `:motion reduced` などで切り替える。

## 文字送りの音

文字が出るときに鳴らす短い音(RPG の「ポポポ」)を、出来事 `TextEvent::Blip(音の ID)` として出す。音を鳴らすのは利用者側。

- 既定では鳴らさない。設定(`RevealOptions::blip`)に `Blip` を入れると本文全体で鳴り、`[blip 音]` の範囲ではその音、`[blip off]` の範囲では鳴らない。設定が無くても `[blip]` の範囲では鳴る
- 鳴らすのは字(仮名・漢字・英数字)だけで、空白・句読点・括弧・記号では鳴らさない。`every` 文字ごと(既定 2)に1度鳴らし、ページの始めと音が変わったところから数え直す
- 前の音から `min_interval` 秒(既定 0.05)たっていなければ鳴らさない。1回の `advance` で返す音は最後の1つだけ、`skip` では鳴らさない(まとめて鳴らないように)
- ボイス(`[voice]`)のある台詞は `[blip]` の範囲の外に書くか、`[blip off]` で囲む

CLI では `--blip 音[,文字数]`、REPL では `:blip 音[,文字数]`(`:blip off` で範囲だけに戻す)。

## オートモード

入力待ちから自動で次へ進むまでの推奨の秒数を `Reveal::auto_wait(ページ, ボイスの長さ)` が返す。シナリオは書き換えなくてよい。進めるのは利用者側で、毎フレーム `Reveal::auto_due` で判定して `Reveal::proceed` を呼ぶ。決め方は設定(`RevealOptions::auto` の `AutoWait`)。

- 読む時間: `base`(既定 1.0 秒)+ `per_char`(既定 0.05 秒)× ページの文字数(空白を除く)。`max`(既定 8 秒)を超えない
- ボイス(`[voice id]`)の長さを渡せば、ボイスが鳴り終わってから `after_voice`(既定 0.5 秒)待つ。読む時間より短ければ読む時間を使う。長さの分からないボイスは数えない
- 最後のページ(終了)では進めない。ゲームの「オートの速さ」は返った秒数に倍率を掛けて使う

CLI では `--auto`(`log` にページごとの待ち時間を出す)と `--voice-len ID=秒`、REPL では `:auto on`。

## 自動改ページ

`LayoutOptions::max_lines` に行数を入れると、その行数を超えたところで自動で改ページする(`[p]` と同じく入力を待つ)。自動改ページの直後の空行は捨てる。CLI では `--lines 行数`、REPL では `:lines 行数`(`:lines off` で切る)。

## 組版の規則

- 禁則(standard): 行頭禁則(句読点・閉じ括弧・小書きの仮名・長音など)、行末禁則(開き括弧)、分離禁止(`……` `――`)。違反するときは前の文字ごと次の行へ追い出す。どの文字がどれに当たるかは、下の分類の表で決める(UAX #14 の分類を JIS X 4051 の和文の約物に合わせて読み替えたもの)

  | 分類 | 行頭 | 行末 | 文字 |
  | --- | --- | --- | --- |
  | 始め括弧・始め引用符 | | 置けない | `「` `『` `（` `(` `［` `[` `｛` `{` `〈` `《` `【` `〔` `〘` `〖` `“` `‘` `〝` `«` `‹` `｟` `｢` |
  | 終わり括弧・終わり引用符 | 置けない | | `」` `』` `）` `)` `］` `]` `｝` `}` `〉` `》` `】` `〕` `〙` `〗` `”` `’` `〟` `»` `›` `｠` `｣` |
  | 感嘆符・疑問符 | 置けない | | `！` `？` `!` `?` `‼` `⁇` `⁈` `⁉` |
  | 句読点・中点・コロン | 置けない | | `、` `。` `，` `．` `,` `.` `・` `：` `；` `:` `;` `､` `｡` `･` |
  | 小書きの仮名・長音・踊り字・波ダッシュ | 置けない | | `ぁ`〜`ゖ` `ァ`〜`ヶ` の小書き・`ㇰ`〜`ㇿ`・半角の `ｧ`〜`ｯ` `ｰ`・`ー` `～` `〜` `゠` `‐` `–` `゛` `゜` `ゝ` `ゞ` `ヽ` `ヾ` `々` `〻` `ﾞ` `ﾟ` |
  | 分離禁止 | | | `…` `‥` `―` `─` `—` `⋯`(同じ字が続くとき、その間で分けない) |
  | ハイフン・スラッシュ | 置けない | | `-` `/` |
  | 前置の記号 | | 置けない | `$` `¥` `£` `€` `₩` `₹` `₽` `₺` `₴` `₱` `₫` `₪` `฿` `＄` `￥` `￡` `￦` `№`(直後が数字なら数と1語) |

- ぶら下げ: 行末の `、` `。` は幅を超えても行に残す(後ろに閉じ括弧が続くときは追い出し)
- 英数字の連続は1語として途中で分けない。ただし、どの行にも収まらない(字下げを引いた行の幅より長い)語だけは、幅からはみ出さないように文字の間で折り返す(前の行の残りも埋める)。`:` `/` `.` などの記号の前後では今までどおり折り返せる。ただし数の中の区切り(`3.14` `1,000` `10:30` `2026/11/10` `2026-11-10`)、数の前の記号(上の表の前置の記号。`US$100` も)と後ろの記号(後置の記号。`100%` `30℃`)は数と1語にする。アクセント付きのラテン文字(`café` の `é`。U+00C0〜U+024F の字)も英字として扱う(和欧間のアキも入る)。折り返した行の後ろの半角空白は行末に残し、次の行の頭には置かない(行末の空白は揃え・両端揃え・行の幅に数えず、線も引かない)。語の後ろに続くハイフン(`well-known`)は前の語に付け、ハイフンの後ろでだけ折り返す。スタイルの境目で分かれた語(`hel[b]lo[/b]`)も1語として扱う(禁則を切っていても分けない)
- 約物の詰め(`punct_squeeze`、既定で有効): 句読点・終わり括弧の後ろに句読点・括弧が続くとき、前の約物の後ろの半角を詰める(`」「` `。」` `、「` など)。始め括弧の後ろに始め括弧が続くとき(`「『` `（「` など)は、後ろの括弧の前の半角を詰め、字形を半角だけ前へずらして描く(`Glyph::shift`。禁則を切っているときは詰めない)
- 和欧間のアキ(`latin_space`、既定 0.25): 漢字・仮名と欧文(半角英数・アクセント付きのラテン文字)の間に四分のアキを入れる。約物との間・行頭・縦書きの縦中横の前後には入れない
- 字下げ(`indent`、既定はすべて 0): 段落(改行・`[br]`・`[p]` で区切られた文)ごとに、地の文の1行目・2行目以降、会話(始め括弧 `「` `『` `（` などで始まる段落)の1行目・2行目以降の字下げを全角の文字数で決める。会話の1行目は 0 で天付き、0.5 で半角下げ、1 で全角下げ。開いた括弧が閉じないまま改行・改ページした続きの段落は、会話の2行目以降と同じ字下げになる。ただし続きの段落が始め括弧で始まるとき(段落ごとに `「` を開き直し、最後の段落だけ閉じる書き方)は新しい会話とし、閉じていない括弧は数え直す。全角の空白で始まる段落は手で字下げしたものとみなし、1行目を下げない。字下げの分だけ行に入る文字は減り、禁則・ぶら下げ・両端揃えは残りの幅で行う。よく使う組み方は `Indent::novel()`(地の文を1字下げ・会話は天付き)と `Indent::dialogue()`(会話の2行目以降を括弧の後ろに揃える)。CLI では `--indent novel|dialogue|off|1行目[,2行目以降]` と `--bracket-indent 1行目[,2行目以降]`、REPL では `:indent`・`:bracket`
- 両端揃え(`justify`、既定は切): 段落の最後の行を除き、幅に満たない行の塊(1文字・英単語・ルビの親文字)の間を均等に広げて行末を揃える。スタイルの境目で分かれた語(`hel[b]lo[/b]`)の中は広げない
- 端末(CLI・REPL)では半角未満の幅を表せないので、約物の詰めと和欧間のアキは既定で切っている(`--tsume` `--wao 比` `--justify`、REPL の `:tsume` `:wao` `:justify`)
- ルビ: 親文字の外へ合計 0.5(全角の半分)まではみ出してよい。それより長いときだけ親文字の間を広げる
- 文字送り: 既定 20 文字/秒。`、` と三点リーダー(`…` `‥`)の後に 0.1 秒、`。！？` の後に 0.3 秒の間を入れる。句読点・三点リーダーの後ろに句読点・三点リーダー・閉じ括弧・閉じ引用符が続くとき(`。」` `！？` `……` `……。`)は、続いた最後の文字の後に、その中で最も長い間を1度だけ置く。数の中の `,`(`1,000`)の後には置かない
